# Bring your own repo

Full checklist lives with the engine: [BYO.md](https://github.com/dentroio/agentic-factory/blob/main/docs/adopters/BYO.md).

Short version: point factory `GITHUB_REPO` at any GitHub repo (this template or your app). Add `docs/project_management/work_orders/` and `docs/factory/runs/`. Copy `PROCESS.md` to `AGENT_PROCESS.md`. Create labels `new-wo`, `agent-pr`, `pm-sync`. You do not need any other private product.
