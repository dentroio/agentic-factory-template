# Optional GitHub workflows

These are **copies** from the factory engine. They are not enabled in this template (only `.github/workflows/ci.yml` runs).

To use one: copy it into `.github/workflows/` in **this** repo. Many call Python scripts that live in [agentic-factory/scripts](https://github.com/dentroio/agentic-factory/tree/main/scripts) — copy those too, or skip the workflow.

Do not paste these into the engine repo’s live `.github/workflows/`.
